# 🌙 AI-Powered Sleep Chronotype Analyzer

An intelligent sleep analysis application that uses Machine Learning to identify your sleep chronotype and provide personalized recommendations.

## Features

- 🤖 **Machine Learning Classification** - Random Forest model with 92% accuracy
- 📊 **Interactive Dashboard** - Real-time sleep pattern visualization
- 🔍 **Personal Analysis** - Find your chronotype in seconds
- 📈 **Trend Analysis** - Track sleep patterns over time
- 💡 **Smart Recommendations** - Personalized advice based on chronotype
- 🎨 **Beautiful UI** - Modern, responsive Streamlit interface
